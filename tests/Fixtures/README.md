# Фикстуры

Файлы, которые песочница харнесса не умеет синтезировать (нет энкодера или
формат слишком сложен). Маленькие, свободные по лицензии, по одному на
формат.

Профиль `archives` — исключение: он берёт `nested.7z` и `locked.zip`
**по имени** (`CopyNamed`), потому что по расширению `.zip` пришёл бы
`texts.zip`, а нужен именно защищённый паролем.

Профили `media` и `docs` берут отсюда **по расширению**, а не по имени:
первый попавшийся файл с нужным расширением. Имя фикстуры значения не имеет
— значение имеет формат, — поэтому файл можно заменить на лучший, не трогая
код. Отсутствующего формата нет и не будет ошибки: в сводке песочницы
появится строка `fixtures: N copied, missing .ogg .opus …`, и сценарий,
которому формат нужен, сам это заметит своей проверкой.

Всё остальное генерирует `SandboxBuilder`: JPEG с EXIF, CR3, DNG,
zip-документы (docx / xlsx / pptx / odt / epub), fb2, md, rtf, pdf, html,
txt в четырёх кодировках, wav с тегами, куб в stl / obj / gltf, `.lnk`,
`.meta`. `.gitignore` игнорирует `*.meta` и `*.lnk` — такие только
генерировать.

## Правило отбора

Своё либо с лицензией, которую можно назвать одной строкой. Репозиторий
публичный (`github.com/lekta/wander`, PolyForm Noncommercial): всё, что
здесь лежит, раздаётся всем, и «файл лежал у меня на диске» — не
основание.

Сайты «бесплатных сэмплов» на это не годятся: у одних прямой
`All rights reserved` в метаданных, у других «all files are free to
download and use» без формальной лицензии и без слова о том, кто автор
снятого кадра. Дешевле всего своё — `ffmpeg` из `tone.wav` и `cover.jpg`,
которые харнесс уже генерирует.

2026), `app_ico.webp` (значок Wander), `texts.zip`, `nested.7z`, `locked.zip`

`Документ из openoffice.doc`, `Новый документ.docx` / `.epub` / `.rtf` /
`.pdf` (экспорт собственного текста из Google Docs — в метаданных ни

**Скачанное убрано** (2026-09-02): `voice-sample-96kbps.m4a` (в атоме
`cprt` прямым текстом `© 2026 Sample-Files.com. All rights reserved.` — не
«серая зона», а прямой отказ), `file_example_WEBP_50kB.webp` с

ничего: ни лицензии, ни автора снимка) и `stereo.flac` оттуда же. Webp
заменён своим `app_ico.webp`; m4a и flac делает `ffmpeg` из `tone.wav`,
который харнесс и так генерирует (`-c:a aac`, `-c:a flac`), когда эти
форматы понадобятся.

## Чего ещё не хватает

Список форматов и зачем каждый — BACKLOG, «QA: добить фикстуры по
форматам». Коротко: видео (mp4 / webm), анимированный gif, flac, m4a,
ogg / opus / aac / m4b / wma, heic, xlsx / pptx от настоящих программ,
chm / msg / djvu (7z, zip с паролем и rar закрыты профилем `archives`).

Проверяются они не глазами: `SandboxBuilder` помнит, что скопировал, а
`Wander.Harness selfcheck` читает каждую фикстуру тем же классом, что и
приложение (теги и обложку — `AudioTags`, docx / epub —
`ZipDocumentExtractor`); для чего читателя нет, печатается строкой
«скопирован». Сценарий `preview-formats` открывает такие форматы шагом
`preview-format` — файла нет, шаг не падает, а пишет в отчёт, какую ветку
панели не открывали.

## `state/`

Отдельная папка: `state.json` чужих сборок, по файлу на версию. Сценарий
просит файл полем `"state": "0.3.0"`, харнесс кладёт его в data-dir прогона
**до** старта приложения; файла нет — прогон падает сразу, а не проходит
молча. Сейчас лежит `0.3.0.json` (снят с рабочей машины 2026-09-02), с ним
работает сценарий `state-upgrade`.

**Пути внутри обезличены, и это часть фикстуры, а не вежливость.** Живой
`state.json` — это имя пользователя, список установленных программ, названия
папок со съёмками и книгами; репозиторий публичный. Поэтому пути заменены на
нейтральные (`C:\Users\user`, `C:\Programs\tool-01`, `D:\Raw\26.06 съёмка`),
кириллица оставлена нарочно: вместе с ней проверяется, что `\uXXXX` из файла
доезжает до дерева живым. Ведут они в никуда — сохранённое состояние с
исчезнувшими папками обычное дело, и приложение обязано пожать плечами.
Кладёшь новый файл — пройдись по нему так же: `Session.LastPath`,
`ManualViewModes`, `ExpandedPaths`, `RecentPaths`, `Favorites`.
