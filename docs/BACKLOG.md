# Wander — бэклог

Конкретные фичи, которые обсудили и **сознательно отложили**: знаем что и
зачем, но не сейчас. Взятое в работу переезжает в PLAN, закрытое удаляется.

## Файловые операции

- **Копирование — вторая очередь (0.6)** (2026-09-22, отложено при спеке
  блока 4 — OPERATIONS.md «Границы»): MTP / PTP — устройства без буквы
  диска, третья ветка shell-namespace с `IFileOperation` как у архивов (у
  MTP одна передача за раз, без докачки, сессия рвётся при засыпании
  камеры); свой движок копирования с хэшем на лету и проверкой после копии
  (`CopyFileEx` байтов не показывает); продолжение после вылета — журнал
  операции на диске и уборка `.wander-tmp`; пауза операции при пропаже
  устройства и автопродолжение по возврату (нужно состояние «пауза» в
  `OperationTracker`); robocopy и небуферизованный ввод-вывод — выигрыш
  только между быстрыми дисками; «Извлечь» через
  `CM_Request_Device_Eject`, если шелл глагол для корня не даёт;
  `IRecycleBin.RestoreMany` (TECHDEBT, стенд: 3 мс на элемент вместо 15).
- **Path too long** (> 260 без `\\?\`) — `longPathAware` в манифесте стоит;
  осталась понятная ошибка как fallback.
- **UNC** — disconnected share / timeout дают долгие таймауты с сырой
  ошибкой; нужны явные таймауты и текст (0.6, вместе с очередью выше).
- **Reparse-points** — `CopyDirectory` ссылки пропускает молча; в 0.5 —
  элемент `Skipped` с причиной (OPERATIONS.md, шаг 11); follow / copy as
  link — по запросу.
- **Альтернативное поведение при «оставить обе папки»** (2026-09-03). Сейчас
  обе галки на паре папок — слияние. Для самых умных — настройка:
  синхронизация (новее побеждает, удалённое удаляется) или папка рядом под
  новым именем. Инструмент синхронизации — PLAN AA.
- **Буфер обмена** — сделан по варианту B2 (спринт 5): зеркалирование наружу
  сразу, чтение при активации; список после чужой операции обновляет
  сторож, виртуальные файлы называются. Осталось: вырезал в Wander, вставил
  в Проводнике — перемещение сделал он, в нашем undo его нет.
- **Часы «в работе»: не показывать, если операция вот-вот кончится**
  (2026-09-23). Часы появляются через 0,4 с (`PathClaims.BadgeDelayMs`) и
  у операций 0,4–0,6 с всё равно мигают. Нужны связь заявки с операцией
  (по токену, как у окна), время работы без вопроса о совпадениях и ожидания
  занятых, доля сделанного; `TransferRate` до 0,5 с молчит, история
  скорости — из записи операции блока 4. То же правило — окну операции.
- **Архив в архиве — вход как в папку (0.6)** (2026-09-23; решение человека:
  сразу виртуальным путём). Сейчас вложенный архив — файл: `Enter` копирует
  его во временную папку и отдаёт ассоциации (у `.zip` — видимо, окно
  Проводника). Оболочка внутрь не смотрит (стенд: `SFGAO_FOLDER` нет,
  `BHID_EnumItems` — `E_NOTIMPL`, путь насквозь не разбирается);
  `ArchivePath` режет по первому архиву (тест). Путь `outer.zip\inner.zip\…`
  — цепочкой, внутренний распаковывается во временную папку по требованию;
  перевод путей в `ParseArchive`, `CanNavigate`, `Enumerate`, `CopyOut`,
  `CreateDataObject` и сверке `ExtractionService`; значок не распаковывает;
  узел в дереве — новый член `IShellNamespace`; исключение `TempExtraction`
  расширяется — в ARCHITECTURE. «Извлечь рядом» внутри — рядом с внешним
  архивом. Фикстура «архив в архиве» — в профиль `archives`.

## Контекстное меню

- **Гасить расширения по приложению, а не по строке** (2026-08-31, выбран
  дешёвый вариант). TortoiseGit — три строки от одного CLSID, три галочки.
  `GetUIObjectOf` отдаёт один склеенный `IContextMenu` — CLSID по строке не
  узнать. Точный вариант — `CoCreateInstance` каждого хендлера в свой
  `HMENU` (так делает ShellExView): переписать `ShellContextMenu`, два пути
  одновременно, свой порядок слияния. Возвращаться, если три галочки станут
  болью.
- **Поднимать пункты расширения на верхний уровень** (у 7-Zip частое — на
  втором уровне; третье состояние скрыт / в подменю / наверху). Дорого:
  `IContextMenu` не даёт стабильного id, «путь» собирался бы из
  локализованных подписей с именем файла.

## Производительность

- **Подвисания при прокрутке галереи — и чем их мерить** (2026-08-31,
  PERFORMANCE). За 2 минуты в RAW-папках окно не рисовало 6,5 с суммарно,
  худший 867 мс; две трети — мимо всех точек `PerfLog`. Порядок: (1) счётчики
  GC (`CollectionCount` по поколениям, `GetTotalAllocatedBytes` на границах
  окна): совпадают с gen2 / LOH — ответ найден; (2) поток миниатюр — 62
  битмапа 256×256/с ≈ 16 МБ LOH/с: пул массивов под PNG, `WriteableBitmap`
  вместо нового `BitmapImage`; (3) потом раскладка — сведение приземлений в
  один проход вместо 192 `Measure`/с. Сосед — PLAN AK (скорость просмотра).
- **Замеры, которые не быстрые** (2026-09-02). Атрибуция «слепых» `ui.stall`
  и пауз GC — только ETW / `dotnet-trace` / dotTrace; дисковый I/O процесса —
  `GetProcessIoCounters` P/Invoke; UIA-набор на релизном exe в Windows
  Sandbox — инфраструктура (PLAN T).

## Панель просмотра

- **CHM** (2026-08-27). ITSF + LZX; `itss.dll` с `IITStorage` распаковывает
  сам. Варианты, общие с `.doc`: (1) не делать; (2) NuGet под формат — чужой
  код читает неизвестные файлы; (3) системные `IPreviewHandler` — PLAN B9.
  Рекомендация — (3); CHM, скорее всего, останется без просмотра.
- **Осциллограмма трека** (2026-08-29). Нужен PCM-декодер: (1) NAudio
  `MediaFoundationReader` — четвёртый пакет, ~1 МБ; (2) `IMFSourceReader`
  через P/Invoke; (3) не рисовать. Взяли (3), кандидат при возврате — (1).
- **Текстуры у моделей** (2026-08-31). Цвет (`Kd`, `baseColorFactor`)
  сделан. Карты меняют всё звено: вершины по парам (позиция, UV), загрузка
  картинок с относительными путями и ужиманием 4096×4096 под 260 px, то же
  отдельно для glTF (`TEXCOORD_0`). Объём — как весь сделанный 3D. У
  PBR-моделей `Kd` всегда `0.8` — их оживят только карты.
- **COLLADA (.dae) и DXF** (2026-08-31). `.dae` — XML, ~300 строк (`<input>`
  со смещениями, `<vcount>`); брать, если попадаются. `.dxf` — не берём.
- **FBX** (2026-08-29). Свой парсер больше всех трёх сделанных вместе;
  AssimpNet — нативная DLL ~15 МБ на архитектуру. Сначала ответить, сколько
  FBX реально лежит в папках. Дёшево при нужде: PLY, 3MF; STEP / IGES — нет.
- **Ролик без длительности на повторе дёргается** (2026-09-03). Файл без
  объявленной длительности повторяется только `Close()` + `Open()`; чёрный
  кадр закрыт `HoldLastFrame`, остаётся пауза на цикл. Варианты: кадры в
  памяти для крошечных клипов; узнать длину через `MediaFoundation` /
  `ffprobe` и перематывать; смириться.
- **Ручная смена ориентации сплита** (2026-09-23). Пару ставит стопкой или
  рядом правило `SplitOrientation` — как пары крупнее; переключатель «стопкой
  / рядом» поверх него. Решить: где кнопка (панель и «Сравнить»), живёт ли
  выбор до конца пары, сеанса или в настройках.
- **Клавиатура в панели просмотра** (2026-08-27). `Ctrl+Q` только
  показывает; `Tab` не входит намеренно. `Ctrl+C` по выделенному мышью
  тексту работает — осталось попадать с клавиатуры: стрелки по типам
  содержимого, `Esc` в список. Развилка общая с PLAN B6.

## Поиск: что доделать

Пять пунктов (2026-08-28), последний закрывает остальные (PLAN, «Обсуждения», G5):

- **Путь у результата виден не везде** — в Значках и Галерее нет места под
  подпись. Подпись под именем ломает высоту ячейки (`TileMetrics`), тултип
  не виден с клавиатуры, переключение в Таблицу отбирает выбор.
- **Кнопка «Перейти»** — `RevealPath` есть, нет точки входа (меню, кнопка,
  `Ctrl+Enter`). Уходит ли выдача — исключение из правила или выдача
  переживает навигацию.
- **Сбрасывать ли фильтр при клике по дереву** — сейчас любая навигация
  сбрасывает (осознанно, REJECTED). Обратный сценарий «только `*.psd` и
  ходить по папкам». Кандидаты: замок в поле; «имя переживает, содержимое и
  подпапки нет»; закреплённый фильтр = сохранённый поиск.
- **Прогресс без знаменателя**. Предварительный проход удваивает время (189
  мс против 200); неопределённый индикатор; прогресс по папкам («12 из 340»,
  очередь `pending` в `ContentSearchService`) — лучший компромисс.
- **Результаты как узлы панели папок** — каждый поиск узел с именем и
  числом; место, переживающее навигацию, закрывает «перейти», «закреплённый
  фильтр» и путь. Решить: где панель (третья секция слева; `Ctrl` + цифры
  заняты); что хранит узел (пути + запрос + время); сколько живёт (сессию);
  клик по узлу — результаты в списке, по папке внутри — переход.

## Операции и свои действия

Отложено при спеке блока AC (2026-09-16).

- **Мнемоники `Alt` у меню шапки и меню «Переход»** — разом на все, когда
  появится «Переход».
- **Частичное совпадение типа в меню «Действия»**: «подходит 2 из 5» и
  запуск по подходящим.
- **Выход инструментов, которые сами называют файл** (soffice
  `--convert-to`): `{out}` не объявить, существующий `{name}.pdf`
  перезаписывается, undo нет. Вариант — `--outdir` во временную папку и
  перенос под уникальное имя (`OutputNames`); флаг у действия.
- **Метаданные при перекодировании в PNG / BMP / GIF**: у кодеров WIC нет
  EXIF-контейнера. XMP в `iTXt` руками или внешний шаг ExifTool.
- **Своё кодирование аудио** без ffmpeg (Media Foundation, `IMFSinkWriter`) —
  если ffmpeg окажется барьером.
- **Прогресс ffmpeg внутри файла**: `-progress pipe:1` даёт `out_time_ms`,
  длительность — ffprobe.
- **Что значит «Изображения» у своего действия** (2026-09-16). Группа = все
  известные картинки, RAW включительно; программа без RAW упадёт с отчётом.
  Варианты: как сейчас; «Изображения» без RAW + отдельная группа RAW; только
  ручной список. Обсудить на первом живом случае.
- **Окно переименования: токены и порядок**. Токены в квадратных скобках
  вводить лень — вставка из списка или кнопки; быстрая сортировка в окне (по
  дате и др.) и ручная перестановка.

## Интерфейс

- **Выделенную ячейку с длинным именем перекрывает сосед снизу**
  (2026-09-03, живое окно). В Крупных значках и Галерее подпись выделенной
  ячейки должна расти вниз поверх соседей. На стенде так и есть
  (`Panel.ZIndex` из `ArrangeOverride`), в живом приложении сосед поверх —
  стенд разницу не воспроизводит. Похоже, контейнер меряется ячейкой:
  `DesiredSize.Height` остаётся в ячейку, `SetZIndex` ставит 0. Подтвердить
  снимком живого окна (`PrintWindow` из работающего приложения). Надёжный
  путь — подпись выделенной ячейки в adorner-слое, как `RenameAdorner`.
  Рост ограничен случаем «выделена ровно одна» (`IsExpanding`). **Чинить в
  живом окне**, иначе круг «поправил — не то».
- **Чего нет против проводника** (разбор 2026-09-03): `Ctrl+D` как синоним
  `Delete`, `F6` как второй `Tab`, `F11` — полный экран, `Ctrl+N` — второе
  окно и средний клик «открыть в новом окне» (упираются в вопрос про
  вкладки; средний клик занят сбросом размера).
- **Вкладки — нужны ли** (2026-08-27). Разделение внимания решают дерево,
  закладки, история; браться с ответом «что вкладки дают сверх панелей».
  Следствие: `Ctrl` + цифры отданы областям окна.
- **Медленный второй клик → переименование** (2026-08-26). В Explorer
  срабатывает случайно; если брать — задержка ≥ `GetDoubleClickTime()`,
  отмена по движению мыши.
- **Панели папок и чужие изменения — `SHChangeNotifyRegister`** (2026-09-23,
  REDESIGN В23). Один регистр уведомлений оболочки на всё окно: дёшево,
  видит папки любой глубины, столп интеграции; не видит изменения из
  консоли и скриптов. Решено пока обходиться `F5` и перечитыванием
  раскрытых уровней при активации окна (P-24). Брать вместе со значком
  корзины (TECHDEBT «Корзина: статичная иконка» просит тот же вызов).

## Хелперы отсмотра — что отложено

- **Честный клиппинг и гистограмма по данным сенсора** (`Sdcb.LibRaw`,
  +2,2 МБ нативных DLL, чужой нативный код читает файл в нашем процессе).
  Отложено человеком 2026-09-22: «в целом нравится, как сейчас, надо
  погонять». Что даст: сегодня клиппинг и гистограмма считаются по 8-битному
  JPEG камеры, то есть видно, что **есть** в тенях и светах, но не что
  вытянется из 14 бит.
- **Балл резкости по точке AF** — сейчас всегда середина кадра, потому что
  камера пишет зону мимо объекта (ARCHITECTURE, «Хелперы отсмотра»).
  Вариант: считать по зоне, когда она правдоподобна (совпадает с тем, где
  кадр резок), иначе по середине; либо отдельная кнопка «по зоне AF».
- **Своя гистограмма у второй половины сплита** — футер один на пару, и
  гистограмма показывает первый снимок. Нужна вторая рядом, если сравнивать
  экспозицию двух кадров окажется частым делом.
- **Хоткеи хелперов** — в 0.5 их нет (решение 2026-09-22); цифры и буквы в
  галерее заняты оценками, свободное сочетание подбирать вместе с M
  (переназначение горячих клавиш).
- **Пороги на глаз** — «резко / мягко / мимо» (70 и 45), порог пикинга 2,0,
  вес точки ¼, порог «точка против линии» (6 точек, вытянутость 2,5).
  Калиброваны на шести кадрах R8; человек смотрит на своих сериях и говорит,
  куда двигать.

## QA: добить фикстуры по форматам

Набор в `tests/Fixtures/` закрывает mp3 (с `APIC`), flac, m4a, webp, doc,
docx, rtf, pdf, epub, zip. Остальное профиль `media` помечает `missing`.
Добирать по одному, когда попадётся подходящий файл:

| Формат | Что открывает |
|---|---|
| **mp4 5–10 с, webm** | миниатюра кадра и транспорт панели — видео-ветки не проверяет ничто (webm — PLAN B10) |
| **gif анимированный** | `GifImage` |
| ogg (Vorbis), opus | «играет / не играет» через Web Media Extensions |
| aac (ADTS), m4b, wma | длительность от проигрывателя, а не по кадрам |
| flac с `PICTURE` | обложка **внутри** файла |
| heic | WIC-кодек (PLAN B10) |
| xlsx, pptx от настоящих программ | `ZipDocumentExtractor` на реальной разметке |
| 7z, rar, zip с паролем | архивы |
| chm, msg, djvu | `IFilter` для msg, «нет просмотра» для chm / djvu |

Правило отбора — `tests/Fixtures/README.md`: своё либо с лицензией в одну
строку; сайты «бесплатных сэмплов» не годятся. Дешевле всего своё: `ffmpeg`
из `tone.wav` и `cover.jpg` харнесса, видео — из кадров `PictureFactory`.
