# Wander — бэклог

Конкретные фичи, которые обсудили и **сознательно отложили**: знаем что и
зачем, но не сейчас.

## Открыто

### Файловые операции

- **Path too long** (> 260 без `\\?\`) — long-path в манифесте + понятная
  ошибка как fallback.
- **UNC** — disconnected share / timeout дают долгие таймауты с сырой
  ошибкой; нужны явные таймауты и текст.
- **FAT32 4 GB** — `IOException` при копировании; подсказка про целевую ФС.
- **Reparse-points** — `CopyDirectory` не различает ссылки: может
  зациклиться или скопировать содержимое. Детектить `ReparsePoint`, решать
  skip / follow / copy as link.

### Контекстное меню

- **Гасить расширения по приложению, а не по строке** (2026-08-31, выбран
  дешёвый вариант). TortoiseGit — три строки верхнего уровня от одного
  CLSID, три галочки. `IShellFolder::GetUIObjectOf` отдаёт один склеенный
  `IContextMenu` — CLSID по строке не узнать. Точный вариант —
  `CoCreateInstance` каждого хендлера отдельно в свой `HMENU` (так делает
  ShellExView, ни один файл-менеджер): переписать `ShellContextMenu`, два
  пути одновременно (вклады самого шелла приходят не от CLSID), свой порядок
  слияния. Возвращаться, если три галочки станут болью.
- **Поднимать пункты расширения на верхний уровень** — у 7-Zip частые
  действия на втором уровне; третье состояние скрыт / в подменю / наверху.
  Дорого: `IContextMenu` не даёт стабильного id, команды нумеруются заново,
  «путь» собирался бы из локализованных подписей с именем файла.

### Производительность

- **Подвисания при прокрутке галереи — и чем их мерить** (2026-08-31,
  PERFORMANCE). За 2 минуты в RAW-папках окно не рисовало 6,5 с суммарно,
  худший 867 мс; две трети — мимо всех точек `PerfLog`. Порядок: (1)
  закрыть слепое пятно — счётчики GC (`CollectionCount` по поколениям,
  `GetTotalAllocatedBytes` на границах окна): совпадают с gen2 / LOH — ответ
  найден; (2) поток миниатюр — 62 битмапа 256×256/с ≈ 16 МБ LOH/с: пул
  массивов под PNG, `WriteableBitmap` вместо нового `BitmapImage`; (3)
  только потом раскладка — сведение приземлений в один проход вместо 192
  `Measure`/с. Не блокер: ошибок нет, данные целы.

- **Замеры, которые не быстрые** (2026-09-02, из QA). Атрибуция «слепых»
  `ui.stall` и пауз GC — только ETW / `dotnet-trace` / dotTrace, строкой в
  логе не решается; дисковый I/O процесса — `GetProcessIoCounters`
  P/Invoke (`Process` его не отдаёт); UIA-набор на релизном exe в Windows
  Sandbox — инфраструктура (wsb-конфиг, общая папка, наличие WebView2 в
  Sandbox проверить). Дешёвое — `SYS`-строка — PLAN S1.

### Закладки

- **«Искать…» для закладки на пропавшую папку** (2026-08-31) — окно поиска
  с маской = имя папки. Отложено: нет области поиска (по всему компьютеру
  дорого, корень в окне не задать — TECHDEBT). Вместе с выбором папки поиска.

### Строки интерфейса

- **Разделить `Strings.resx`** (2026-08-31). Аксессор уже разложен по
  областям (partial `Strings.*.cs`) — навигацию это дало. Делить resx:
  четыре `ResourceManager` на `Get(key)`, `check-strings` ловит дубли между
  файлами, сателлиты на каждый. Возвращаться со вторым языком — переводчику
  файл на область.

### Панель просмотра

- **CHM** (2026-08-27). ITSF + LZX; в системе `itss.dll` с `IITStorage`
  распаковывает сам, дальше стартовая тема и ресурсы. Варианты, общие с B5:
  (1) не делать; (2) NuGet под формат — чужой код в процессе читает
  неизвестные файлы; (3) хостить системные `IPreviewHandler` (то, чем
  показывает Проводник) — закрывает `.doc` / `.xls` / `.ppt` и всё
  зарегистрированное, ложится на столп интеграции; цена — `HwndHost`,
  `IInitializeWithFile` / `Stream`, CLSID из реестра, зависит от
  установленного. Рекомендация — (3) отдельным скоупом; CHM, скорее всего,
  останется без просмотра.
- **Осциллограмма трека** (2026-08-29). Нужен PCM — декодер, не разбор
  тегов. (1) NAudio `MediaFoundationReader` — mp3 и flac одним классом,
  четвёртый пакет, ~1 МБ в exe; (2) `IMFSourceReader` через P/Invoke — без
  пакета, заметный COM-interop; (3) не рисовать — транспорт и без неё полный.
  Взяли (3), кандидат при возврате — (1).
- **Текстуры у моделей** (2026-08-31). Цвет (`Kd`, `baseColorFactor`)
  сделан. Карты меняют всё звено: вершины разворачиваются по парам
  (позиция, UV); модель — список частей по `usemtl` (уже есть); загрузка
  картинок с относительными путями, пробелами, отсутствующими файлами и
  ужиманием 4096×4096 под 260 px; то же отдельно для glTF (`TEXCOORD_0`,
  буфер или файл). Объём — как весь сделанный 3D. У PBR-моделей `Kd`
  всегда `0.8` — их оживят только карты.
- **COLLADA (.dae) и DXF** (2026-08-31). `.dae` — XML, ~300 строк, сложность
  в `<input>` со смещениями и `<vcount>`; брать, если реально попадаются
  (вытесняется glTF). `.dxf` — не берём: 2D-чертёж, `3DFACE` редок; если
  когда-то, то как 2D-просмотрщик. `.mtl` открывается как текст.
- **FBX** (2026-08-29). Версионированное дерево узлов, deflate-массивы,
  слои геометрии, текстовый вариант — свой парсер больше всех трёх
  сделанных вместе. AssimpNet — нативная DLL ~15 МБ на архитектуру, ломает
  однофайловый exe. Сначала ответить, сколько FBX реально лежит в папках
  (хранят `.blend` / `.max` / `.c4d`, их не читает и Assimp). Дёшево при
  нужде: PLY (STL с заголовком), 3MF (zip + XML); STEP / IGES — нет.

### Поиск: что доделать

Пять пунктов (2026-08-28), последний закрывает остальные:

- **Путь у результата виден не везде** — в Значках и Галерее места под
  подпись нет. Варианты: подпись под именем (ломает высоту ячейки из
  `TileMetrics`), тултип (не видно с клавиатуры), переключение в Таблицу
  (отбирает выбор). Зависит от панели поисков.
- **Кнопка «Перейти»** — `RevealPath` есть, нет точки входа (меню, кнопка,
  `Ctrl+Enter`). Решить: уходит ли выдача (навигация сбрасывает поиск) —
  исключение из правила или выдача переживает навигацию (панель поисков).
- **Сбрасывать ли фильтр при клике по дереву** — сейчас любая навигация
  сбрасывает (осознанно, REJECTED объясняет чем кончилось). Обратный
  сценарий «только `*.psd` и ходить по папкам». Кандидаты: «закрепить
  фильтр» (замок в поле), «имя переживает, содержимое и подпапки нет»
  (правило из двух половин), закреплённый фильтр = сохранённый поиск.
- **Прогресс без знаменателя** — «найдено N, просмотрено M». Варианты:
  предварительный проход по каталогам (189 мс против 200 всего —
  удвоение), неопределённый индикатор, прогресс по папкам («12 из 340»,
  знаменатель растёт по ходу — очередь `pending` в `ContentSearchService`
  его знает). Третий — лучший компромисс.
- **Результаты как узлы панели папок** — каждый поиск узел с именем и
  числом, разворачивается в папки; даёт результатам место, переживающее
  навигацию, — закрывает «перейти», «закреплённый фильтр» и путь (виден по
  вложенности). Решить: где панель (третья секция слева — у левой панели
  свой сплиттер, высота, область; `Ctrl` + цифры заняты); что хранит узел
  (пути — снимок, критерии — запрос; скорее оба + время); сколько живёт
  (сессию; между запусками — снимок недельной давности); клик по узлу —
  результаты в списке, клик по папке внутри — переход.

### Поиск: разобранное и отложенное

- **PDF без системного фильтра** (2026-08-27, G4). (1) оставить — честный
  счётчик «не прочитано»; (2) PdfPig (Apache-2.0, ~1,5 МБ, CID-кириллица) —
  четвёртый пакет, чужой парсер; (3) свой разбор подмножества — кириллица
  через CID, ошибиться легче всего там. Решено (1): экстрактор подключается
  одной строкой в `PlatformBootstrapper`, решение не дорожает.
- **Флаги поиска в строке фильтра** (2026-08-28). За: полная запись поиска,
  копируется. Против: второй синтаксис поверх первого; свободны только
  `< > " / \ |`, любой законен внутри текста. Если делать — флаги в начале
  строки, до маски. Пока хватает подсветки `⋮`.
- **Кодировки в побайтовом поиске** (2026-08-28). Сравниваются только
  ASCII-байты; в exe строки лежат как `char*` и `wchar_t*` (UTF-16LE).
  Добавить UTF-8 + UTF-16LE (каждое удваивает проход), если появится
  запрос; «нашлось в одной из четырёх кодировок» необъяснимо.
- **Кэш результатов последних поисков** (2026-08-28). Только для содержимого
  или области шире папки. Решить: ключ — весь `SearchRequest`; хранить
  `FileSystemEntry` (снимок, врёт про размер — перечитывать stat или
  помечать временем); потолок и вытеснение как `ExtractedTextCache`;
  незавершённый поиск не кэшировать; статус-бар говорит «найдено тогда-то,
  `F5`».
- **Поиск сквозь `.lnk`** (2026-08-28). Решить: дубликаты (файл и ярлык —
  ключ по конечному пути); что показывать (ярлык или цель); область (ярлык
  наружу); циклы (множество посещённых целей).

### Интерфейс

- **Клавиатура в панели просмотра** (2026-08-27). `Ctrl+Q` только
  показывает; в обход `Tab` не входит намеренно (остановка, где нечего
  делать). Понадобится, когда из панели захочется взять текст, запустить
  ролик, листать PDF — тогда стрелки по типам содержимого и `Esc` в список.
- **Вкладки — нужны ли** (2026-08-27, из Roadmap). Разделение внимания уже
  решают дерево, закладки, история; браться с ответом «что вкладки дают
  сверх панелей». Следствие: `Ctrl` + цифры отданы областям окна.
- **Медленный второй клик → переименование** (2026-08-26). В Explorer
  срабатывает случайно; если брать — задержка ≥ `GetDoubleClickTime()`,
  отмена по движению мыши.
- **Переключатель языка** (2026-08-26). Механика готова
  (`Strings.<culture>.resx`); без второго перевода — пустая настройка.
  Когда: `AppSettings.Language`, `CurrentUICulture` в `OnStartup`,
  перезапуск окна (`x:Static` не перечитывается). Хвост: русские литералы
  Core в `ContextMenuCatalog` и `PathSafety.FormatReason` — свой resx в Core.

### Галерея

- **Метки (теги)** — [обсудить] (2026-08-27). Звёзды — «насколько хорош»,
  метка — «к чему относится» («на печать», «клиенту»). Решить: хранение
  (`.xmp` `dc:subject` читают Adobe / darktable / exiftool; `.pp3` не
  умеет; своя база нарушает интеграцию); файлы без сайдкара (`.txt`, папка)
  — второй механизм = два источника правды; словарь (свободный ввод
  расползается); отбор «И/ИЛИ» — та же форма, что J3 и G3, один раз на три.
- **Поворот и коррекция в галерее** (2026-08-27). Поворот тегом
  `Orientation` — дёшево и обратимо, но уважают не все, камеры пишут своё,
  RAW не пишем; lossless JPEG (DCT) — своя реализация или зависимость, не
  работает при размерах не кратных MCU; перекодирование — отвергнуть.
  Заодно рассмотреть: полноэкранный просмотр по `Enter` / `Space` (самый
  заметный пропуск), сравнение двух рядом, «в отбор» отдельно от звёзд,
  гистограмма, группировка по дате. Принцип: галерея показывает и
  размечает, но не проявляет.

### QA: добить фикстуры по форматам

2026-09-02. Набор в `tests/Fixtures/` закрывает mp3 (с `APIC`), flac, m4a,
webp, doc, docx, rtf, pdf, epub, zip. Остальное профиль `media` честно
помечает `missing` в сводке, и сценарии на эти форматы ничего не
утверждают. Добирать по одному, когда попадётся подходящий файл, а не
разом:

| Формат | Что открывает |
|---|---|
| **mp4 5–10 с, webm** | миниатюра кадра и транспорт панели (кнопка, полоса, время) — сейчас видео-ветки не проверяет ничто |
| **gif анимированный** | `GifImage`; был, удалён вместе с мемом |
| **m4a** | iTunes-атомы в `AudioTags` |
| ogg (Vorbis), opus | «играет / не играет» через Web Media Extensions |
| aac (ADTS), m4b, wma | длительность от проигрывателя, а не по кадрам |
| flac, в том числе с `PICTURE` | Vorbis-комментарии и обложка **внутри** файла |
| heic | WIC-кодек |
| xlsx, pptx от настоящих программ | `ZipDocumentExtractor` на реальной разметке |
| 7z, rar, zip с паролем | секция P (архивы) |
| chm, msg, djvu | `IFilter` для msg, «нет просмотра» для chm / djvu |

Правило отбора — в `tests/Fixtures/README.md`: своё либо с лицензией,
которую можно назвать одной строкой. Сайты «бесплатных сэмплов» на это не
годятся: у них либо прямой `All rights reserved`, либо «free to download
and use» без формальной лицензии, и кто автор снятого кадра — не сказано.
Дешевле всего своё: `ffmpeg` из `tone.wav` и `cover.jpg`, которые харнесс
уже генерирует, даёт аудио любого формата с настоящими тегами, а из
последовательности кадров `PictureFactory` — видео нужной длины.

## Закрыто

- `Shift+Delete` — всегда подтверждение, затирает undo-стек.
- Прогресс долгих операций — `BatchExecutor` + `OperationTracker` +
  `ProgressDialog`; гранулярность по байтам — TECHDEBT.
- Кэш миниатюр (спринт 4) — три уровня, DONE.
- Буфер обмена (спринт 5) по варианту B2 — зеркалирование наружу сразу,
  чтение при активации; список после чужой операции обновляет сторож,
  виртуальные файлы называются. Осталось: вырезал в Wander, вставил в
  Проводнике — перемещение сделал он, в нашем undo его нет.
