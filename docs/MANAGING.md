# Wander — управляющий чат

Как вести блоки PLAN из одного чата, а делать их пачками в отдельных
сессиях. Читает управляющий чат; пачке — «Размер пачки» и «Заметка передачи»;
роли и инструкции — WORKFLOW.
Решения человека 2026-11-17: [управляющий чат — облегчённо: в рабочем
дереве пишет одна пачка, параллельно — только читающие сессии].

## Когда

Слова «это управляющий чат». Чат ведёт блоки PLAN: бриф, запуск, очередь,
отчёт человеку; выполнение — пачками в отдельных сессиях.

## Цикл

1. Блок — индекс PLAN и раздел блока (CLAUDE.md, «Доки — разделами»).
2. Спеки нет — пишет управляющий по «Спека блока» (WORKFLOW): по разведке
   (Explore или читающая пачка) и по задетым разделам доков; холодное
   чтение агентом `cold-read` — там же.
3. Бриф по шаблону ниже; точки входа — из заметки передачи прошлой пачки
   той же области, нет её — узким поиском.
4. Запуск — `start_session` в этой же папке, без worktree, только с
   сообщения человека. Пачка с кодом — перед запуском проверить Rider
   (WORKFLOW, «Rider открыт»), не отвечает — напомнить в том же сообщении.
5. Пачка закончила (по её отчёту) — человеку очень кратко: что сделано,
   что ждёт (ответа в ней, очереди, прогона глазами), ссылка на сессию.
   Вопросы пачек не пересказывать — человек отвечает в них сам. Полный
   отчёт пачки читать, только если от него зависит следующий бриф.
6. Следующий бриф.

## Очередь

В рабочем дереве пишет одна пачка: git — человека, диф общий и
незастейджен, `check.bat` один. Следующая пишущая — после сдачи
предыдущей; параллельно — только читающие (спека, примерка, стенд в
scratchpad). Примерка до принятия живёт в артефакте или scratchpad и в
дерево не пишет — поэтому её сессия читающая, даже если потом она же
пишет код (WORKFLOW, «Фича: четыре этапа», «Визуальное — примеркой»);
файл в `docs/prototypes/` при принятии пишет пишущая пачка в своей
очереди. Находка или баг от человека — сначала строка в PLAN, потом
бриф; правка сданного — свежей пачкой, не сообщением в сданную.

## Размер пачки

Черта контекста 300k — WORKFLOW, «Блок по спеке», п. 6. В пачке 1–3
шага блока или мелочи одной области; одну мелкую задачу пачкой не
запускать — ждёт соседей по области; исключение — правка сданного, она
идёт свежей пачкой («Очередь»).

## Модели

| Кто | Модель | Что |
|---|---|---|
| Управляющий | Фабле | решения, флоу, бриф, спека; доки и код целиком не читает (разделы — читает) — разведка Explore или читающей пачкой |
| Пачка с кодом | Опус | код, доки области, отчёт |
| Ревью, поиск | Sonnet | агент `review`, Explore |
| Холодное чтение | Опус | агент `cold-read` |

## Субагенты пачки

Код пачка пишет сама. Ревью — одно, в конце (WORKFLOW, «Блок по спеке»,
п. 7). Поиск — Explore. `cold-read` — только для дока-задания другой
сессии; сколько — WORKFLOW, «Спека блока».

## Заметка передачи

`docs/private/handoff/<ГГГГ-ММ-ДД>-<блок>.md` (вне гита): сделано; не
сделано; «Код: `файл:метод` — что там» по задетому; что глазами; открытые
вопросы. Пишет пачка на сдаче и на черте 300k; следующая пачка той же
области получает её путь в брифе.

## Финализация

Отдельной сессией по FINALIZING.md, по слову человека.

## Шаблон брифа

```
Первым шагом: Rider по MCP (не отвечает — сказать человеку до кода),
затем раздел PLAN «<раздел>».
Сверх PLAN: <решения из разговора, связи с соседними пачками>.
Точки входа: `файл:метод` — что там; ...; заметка передачи — <путь>.
Доки: <док, «раздел»>; ...
Дерево: <чьё незакоммиченное, кто ещё пишет>.
Правила пачки: WORKFLOW, «Блок по спеке».
```

Текст задач из PLAN в бриф не вставлять — пачка читает раздел сама.

## Мера

База — сводка скрипта `--since 2026-10-25 --until 2026-11-16`, 26
сессий, до правок процесса 2026-11-17: пик контекста — медиана 275k;
выше 300k — 12 из 26, на них 78 % денег; старт до первой правки кода —
медиана $2.15; доков на сессию — медиана 23k; по виду работы — чтение
кода 34 %, доков 11 %. Чаще всего читались (сессий, токенов): PLAN — 21,
170k; PREVIEW — 12, 74k; QA — 12, 52k; WORKFLOW — 11, 48k. Разовым
замером того же периода, скрипт их не считает: чтение кэша — 55 % денег;
первый запрос — 82k, из них `CLAUDE.md` и индекс памяти — по ~7k.
Деньги — оценка по ставкам скрипта, важны доли.

Замер — `python -X utf8 tools\session_costs.py --since <ГГГГ-ММ-ДД>`:
сводка в консоль, строка на сессию — `artifacts\metrics\sessions.jsonl`.
Сравнивать после 2–3 пачек, не после каждой.
