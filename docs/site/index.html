Wander

Медиа-менеджер для Windows

Скачать Wander {{version}}

Бесплатно для личного использования. Без установки: один файл на 74 МБ, запускается сразу. Работает в Windows 10 и 11.

Удобная навигация

Дерево папок сохраняется между сессиями. Закладки задаются перетаскиванием, могут раскрываться.

Быстрый просмотр

Множество форматов: изображения, RAW, видео, документы. Файл показывается сразу, как только выделен, а два выделенных встают рядом для сравнения.

Отбор фотографий

Папка со снимками открывается галереей, резкость и клиппинг можно увидеть на миниатюрах. Оценки ставятся с клавиатуры, их понимают программы Adobe, darktable и RawTherapee.

Групповые операции

Переименование набора файлов по шаблону. Конвертация форматов - изображения, видео, документы. Умное решение конфликтов со сравнением по содержимому.

Гибкое контекстное меню

По умолчанию использует меню в стиле Win10 со всеми пунктами, но лишние можно скрыть и добавить свои действия.

Надёжность и безопасность

Код покрыт тестами, а сборка прогоняется сценариями. Репозиторий открыт, релиз собирается гитхабом. Удалённое идёт в корзину, системные папки защищены.
