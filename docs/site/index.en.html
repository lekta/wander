Wander

Media manager for Windows

Download Wander {{version}}

Free for personal use. No installation: a single 74 MB file that runs right away. Works on Windows 10 and 11.

Easy navigation

The folder tree is kept between sessions. Bookmarks are added by dragging and expand like folders.

Fast preview

Lots of formats: images, RAW, video, documents. A file shows the moment it is selected, and two selected files sit side by side for comparison.

Photo culling

A folder of photos opens as a gallery, with sharpness and clipping visible right on the thumbnails. Ratings are set from the keyboard and read by Adobe apps, darktable and RawTherapee.

Batch operations

Rename a set of files with a template. Convert images, video and documents. Smart conflict resolution that compares file contents.

Flexible context menu

A Windows 10 style menu with every item by default: hide the ones you never use and add actions of your own.

Reliable and safe

The code is covered by tests, and builds are run through scenarios. The repository is open, and GitHub builds the releases. Deleted files go to the Recycle Bin, and system folders are protected.
