## Verdict

Written by hand, and it is the point of the file: what moved against the previous
version, what was decided about it, what stays a known cost. A number with no verdict
is noise a year later.

First snapshot in this folder; the previous version is compared through
PERFORMANCE.md (0.3.0, 2026-08-31) and the harness table in QA.md (2026-09-02).

- weight: 74.0 MiB against 73.8 on 0.3.0 - noise; size-report not run, the move is
  under a megabyte.
- startup: first frame 1502 ms against 1878-2051 on 0.3.0 and the ~1650 baseline of
  2026-08-27. One release session of three minutes, same 27-item start folder, so a
  single sample; the gain is section R (lighter tile templates, hidden views not
  built), not a fluke of the folder.
- responsiveness: one ui.stall of 156 ms in three minutes; first screen median 192 ms,
  worst 870 (cold start); the one "folder listed" over 300 ms is the start folder
  with covers. Nothing to act on.
- memory and GC: harness in Debug, latest run per scenario is the post-fix run of
  20:23 - WS peaks 442-573 MB against 439-562 on 2026-09-02, gen2 4-5 per scenario,
  unchanged. soak-30 (18:40, before the day's fixes; they touch no memory path):
  peak 690 MB, +76 MB from the end of the first minute over 29 minutes against a
  150 MB limit, handles 867..1082 and back to 980 at the end, LOH 153 MB peak and
  53 MB at the end - collected, not accumulated; gen2 41 in thirty minutes.
- regressions, and where they went: none. Known costs carried over: the 5-8 s
