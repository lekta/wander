**Структура GUIDE = структура сайта.** `#` — заголовок руководства. `##`
без `###` внутри — самостоятельная страница (сейчас одна, «Начало
работы»); `##` с `###` — группа: заголовок в навигации, своей страницы
нет, текст под ним запрещён. `###` — страница, `####` — оглавление внутри
неё. Порядок — порядок в файле. Слаг страницы уникален среди страниц,
якорь `####` — внутри страницы; «Полный экран» как страница и как
подраздел «Горячих клавиш» — допустимо. Списки расширений — только на
странице «Форматы»; остальные говорят «картинки» и ссылаются туда.

**Генератор `tools/site`** — консоль на C# с Markdig, в решении
(`check.bat` собирает и форматирует), без ссылок на App и Core. Вход:
`docs/GUIDE.md`, `docs/site/index.html` (лендинг), `docs/screenshots/*.webp`,
шаблон и CSS в `tools/site/`. Выход `_site/`: `index.html`,
`guide/<slug>/index.html`, `versions/index.html`, `img/`. Делает:

- режет GUIDE по правилу выше; страница — заголовок, оглавление из `####`,
  текст, «назад / дальше»; боковая навигация — группы и страницы;
- слаги и якоря — транслит заголовков; дубль — ошибка; ссылка `#якорь` на
  раздел другой страницы переписывается в её путь; `../README.md`,
  `SECURITY.md`, `PLAN.md`, `BACKLOG.md` — на GitHub;
- «Версии» — из `git tag -l v*`: релиз и GUIDE тега;
- лендинг копирует, заполняя плейсхолдеры версии и ссылки «Скачать»;
- битая внутренняя ссылка — ненулевой выход;
- ссылки относительные: одно и то же работает в подпапке, в корне и
  локально из файла; широкие таблицы — горизонтальная прокрутка CSS.

**Скорость.** Ни строки JS. Системный стек шрифтов, никаких веб- и
иконочных шрифтов. CSS инлайном в каждую страницу (единицы КБ). Картинки —
`<img>` с `width` / `height`, ниже первого экрана `loading="lazy"`. Тёмная
тема — `prefers-color-scheme`. Ориентир: страница руководства 10–30 КБ,
лендинг с двумя-тремя скриншотами — до 300 КБ.

**Правило скриншотов (2026-09-25).** В репозитории только WebP,
`docs/screenshots/*.webp`; на них ссылаются README и сайт (GitHub WebP
рендерит). PNG рендерит харнесс в `artifacts\`, в репозиторий не
попадает. Конвертирует человек руками при обновлении снимка, ffmpeg (тот
же, что у действий Wander; `winget install Gyan.FFmpeg`):

```pwsh
ffmpeg -i main.png -c:v libwebp -quality 90 -preset text -compression_level 6 main.webp
```
