# Security Policy

Wander — локальное десктоп-приложение: серверной части, аккаунтов и передачи
данных наружу нет, поэтому поверхность атаки ограничена самим приложением и его
операциями с файловой системой.

## Поддерживаемые версии

Поддерживается только последний бета-релиз. Фиксы выходят в новых версиях.

| Версия | Поддержка |
|--------|-----------|
| 0.2.x  | ✅        |
| < 0.2  | ❌        |

## Как сообщить об уязвимости

Не открывай публичный issue для уязвимостей. Сообщи приватно:

- через **GitHub → Security → Report a vulnerability** (Private vulnerability
  reporting; включается в настройках репозитория), либо
- написав автору на адрес, указанный в его [профиле GitHub](https://github.com/lekta).

Проект развивается силами одного человека — ответ и фикс по мере возможности,
без гарантированных сроков и без bug bounty. Спасибо за ответственное раскрытие.
