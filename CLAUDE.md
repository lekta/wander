# CLAUDE.md — точка входа

**Wander** — файловый проводник для Windows 11 (WPF, .NET 10), замена
Explorer: убрать лишнее, починить его баги, добавить удобств.

## Карта (`docs/<ИМЯ>.md`)

- ARCHITECTURE — столпы, правила кода, слои, композиция, состояние и
  логи, настройки, строки, тесты, кодстиль; «Области» — где механизмы
- FILEOPS (операции, копирование, устройства, архивы), WINDOW (модель
  окна, панели, контролы, тема, значки), LISTING (сессия папки, выделение,
  буфер, поиск, галерея), MENU (меню и действия), PREVIEW (панель
  просмотра, форматы)
- PLAN — что делаем (индекс в голове); DONE — что работает; BACKLOG —
  отложенное; TECHDEBT — мелочь по пути; REJECTED — отказы с причиной
- WORKFLOW — роли, этапы, инструкции и их слова; MANAGING — управляющий
  чат и пачки; FINALIZING, PRERELEASE, RELEASING — финализация, подготовка,
  релиз; SIGNING — подпись exe
- QA — уровни проверки, матрица «трогал → проверь»; qa_harness —
  песочница, харнесс, сценарии; qa_checklist — ручной чек-лист;
  PERFORMANCE, `measurements/` — вес, старт, замеры
- GUIDE, GUIDE.en — руководство; SITE — сайт и правила GUIDE; CHANGELOG,
  CHANGELOG.en; CONTRIBUTING, SECURITY; README, README.ru в корне;
  `docs/prototypes/` — принятые примерки; `docs/private/` — вне гита;
  `deps.txt` — граф папок

- Операция с файлами — FILEOPS, «Файловые операции»; ARCHITECTURE, «Как

- Настройка — ARCHITECTURE, «Новая настройка — по шагам»; формат —

- Новое окно, панель, контрол, заметная смена вида — сначала примерка
  (WORKFLOW, «Визуальное — примеркой»); контролы — WINDOW, «Окно и его
  контролы»; цвета — WINDOW, «Цвета — один словарь»
- Посадка строк, выделение — LISTING, «Сессия папки»
- Свой запуск exe — QA, «Уровни проверки», абзац Smoke
- Слово человека («финализируй», «готовимся к релизу», «делай блок» …) —
  таблица WORKFLOW, «Инструкции»

**Доки — разделами**: заголовки grep-ом (`^#{2,3} `), раздел по offset,
целиком не читать; инструкцию (FINALIZING, PRERELEASE, RELEASING) — по
всем пунктам. Новая сессия: этот файл → индекс PLAN → свой раздел →
задетое в ARCHITECTURE и доке области; блок — WORKFLOW, «Блок по спеке».
DONE, TECHDEBT, BACKLOG, REJECTED — поиском по имени.

**Списки.** Цель → PLAN; отложенная задача → BACKLOG; мелочь по пути →
TECHDEBT; не делаем → REJECTED с причиной; «когда-нибудь» → PLAN,
«Направления (P3)»; закрытое → DONE, из PLAN **удаляется**, не
помечается (FINALIZING, п. 4). Остальные списки сам не чистить — по
согласованию. Память Claude — только про человека и разговор с ним;
правила и факты проекта — в доке.

**Доки — сжато**: факты, решения, имена; история — CHANGELOG и гит; «см. в
X» — только где карта не отвечает. Решения человека 2026-09-29: даты —
только у решений человека и правил; «раньше было X» — причиной в один
оборот или удалить; заголовки и жирные начала пунктов, на которые
ссылаются другие доки, не переименовывать. Сжимать написанное — по
запросу. GUIDE — по своим правилам (SITE, «Как пишется руководство»).

## Столпы — подробно ARCHITECTURE, «Столпы»

1. **UX** лучше Explorer, интерфейс компактный: значок вместо слова, слова
   — в подсказке; точка-разделитель «·» — нигде.
2. **Надёжность**: деструктивное — диалог с **Cancel по умолчанию**; всё,
   кроме безвозвратного удаления, откатывает `Ctrl+Z`.
3. **Интеграция с системой**: буфер, drag & drop, ассоциации, меню,
   хоткеи — системные; изоляция — решением человека; не работает —
   остановиться и вынести.
4. **Скорость просмотра**: снимок мгновенно на глаз, без мельканий.

## Правила кода — подробно ARCHITECTURE, «Правила кода», «Кодстиль»

- Core без Windows и UI: ни `System.Windows.*`, ни COM, ни PInvoke —
  интерфейс в Core, реализация в `Wander.Platform.Windows`.
- Сервисы — `ServiceLocator`, композиция одна; без DI и MVVM-фреймворков.
- Тесты только Core; правило и машина состояний — в Core, где их достаёт
  тест; вью исполняет.
- Список не дёргается от правки внутри строки; выделенный файл не уходит
  с экрана — посадка строк только через модель окна.
- **Новая операция с файлами**: `SystemPathGuard`, лог, `IUndoableAction`,
  деструктивная — подтверждение с Cancel по умолчанию.
- **Текст для пользователя** — только `Strings.resx` и `Strings.en.resx`,
  ключ — в оба; Core — через `ITextSource`.
- Комментарии в коде — только ASCII.

## Проверка

```pwsh
.\tools\check.bat          # build → format --verify → строки, ключи XAML → сайт → тесты
.\tools\check.bat run      # + smoke (окно за экраном); при финализации обязателен
.\tools\check.bat format   # применить форматирование
```

Из PowerShell, из корня; код 0 — зелено, иначе код первого упавшего шага.
Через `cmd /c` из bash не запускать: вернёт 0 и проглотит вывод. Перед
коммитом — полный.

## Экран, ввод, данные человека

- **Ввод не эмулировать, окна поверх экрана не поднимать**: ни
  `SetCursorPos` / `mouse_event` / `SendKeys` / `SetForegroundWindow`, ни
  кликов «проверить» — на этом экране работает человек.
- **Сценарии харнесса** (`Wander.Harness run`, `check.bat qa`) — только по
  словам «прогони / запусти автотесты …» и «готовимся к релизу»
  (2026-09-16); «финализируй» их не запускает: назвать задетые и ждать.
  Из сессии Claude — с `--rebuild`: `%TEMP%` и `%LOCALAPPDATA%` у
  инструментов виртуализированы, старая песочница пуста.
- **Данные человека** (2026-09-04): его копия — `C:\Programs\Wander`,
  данные — `%LOCALAPPDATA%\Wander`. Exe запускать только с `--data-dir`
  под `artifacts\` и `--folder` на тестовую папку (`tests\Fixtures`,
  песочница); `publish.ps1 -Run` / `-Install` и голый `Wander.exe` — нет.
  `state.json` из сессии виден устаревшей копией — спрашивать, не читать;
  логи (`%LOCALAPPDATA%\Wander\logs`) живые — читать всегда, не
  спрашивая (2026-10-23).
- Чего не проверить — в отчёт списком «посмотреть глазами».

## Git — только чтение

`status`, `log`, `diff`, `show`, `ls-files`, `ls-tree`, `blame`,
`check-ignore`, `tag` (список). Мутирующее (`deny` в
`.claude/settings.json`, `tag <имя>`) — человек; без явной просьбы не
делать. Файлы двигать на ФС, не `git mv`; `.gitignore` править, не
`git rm --cached`. Результат незастейджен, в отчёте — что изменилось.
Скрипты `tools\` git-команды печатают, не выполняют.
